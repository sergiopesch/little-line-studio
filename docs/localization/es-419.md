# Latin American Spanish — es-419

Working editorial guide, grounded in the current Cat script. Native-speaker review and human listening remain pending. Follow the [shared workflow](README.md).

## Audience and voice

Use the current child-facing tú forms. For the family together, the interface uses ustedes forms such as “Elijan” and “pueden”. This broad locale uses the approved Venezuelan Carito voice; do not describe every choice as universal across Latin America.

Preserve Carito’s approved identity. Listen to “doble ve”, little repeated cues and colour names in context. A script match cannot establish a natural Venezuelan delivery.

## Vocabulary and adaptation

Current project choices include “agrega”, “rosado”, “hacia afuera” and “no hay apuro”. Use diminutives sparingly for warmth and scale, without making every instruction babyish.

The mouth uses “doble ve”; Spain uses a different letter name. Keep the two-curves explanation so understanding does not depend on knowing the alphabet.
