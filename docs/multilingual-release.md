# Multilingual narration releases

Each prepared voice has its own locale ID, source plan, narration index, durations, manifest and availability descriptor. British English is `en-GB`, Irish English is `en-IE`, Scottish English is the application-specific BCP 47 private-use variant `en-GB-x-scotland`, Latin American Spanish is `es-419`, and French is `fr-FR`. A voice or language must not silently fall back to another locale's narration. Scottish and Irish English currently share the authored English teaching text; their voice recordings remain separate.

French lesson records under `research/french-reviewed` are source-linked to the English lesson and geometry. `scripts/export-reviewed-french.mjs` verifies every source hash, phase and step before producing the French runtime catalogue and narration text. Its review status records assistant review only. Independent native-speaker review and full human listening remain separate from all automated checks.

The offline locale planners create deterministic request plans. `scripts/multilingual-audio-runner.py` stages approved speech plans only after validating locale, voice, model, transcripts and request identities. It uses a durable shared account ledger, an exclusive process lock, conservative reservations, disabled overages and no automatic paid-request retries. A pending or blocked ledger must be reconciled before continuing. Provider credentials, ledgers, raw responses and generation caches are local ignored files; they never belong in the repository or deployed assets.

`scripts/three-language-cat-pilot.py` plans source-linked Cat auditions for Spain Spanish, German and Italian. The default invocation is offline; `--run --shared-root <existing-checkout>` uses that checkout's existing credential, shared cache and 560,000-credit ledger, under the same exclusive lock and no-retry safeguards. It stages only Cat audio, never enables a language, and fails if the entire pilot exceeds guarded headroom. Its assistant-reviewed texts and staged recordings remain subject to independent native review and human listening. The account must have the exact selected voices and an appropriate provider permission route; voice-library previews alone are not finished recordings.

Each locale's offline validator checks its complete source and staged bundle, including request identities, audio metadata and cache receipts, before producing release metadata. `scripts/prepare-build.mjs` independently checks the selected locale against source text, voice, keys, durations and asset hashes. A new locale remains unavailable while its availability descriptor is empty; the build requires the complete 30-lesson catalogue when enabled. These checks do not evaluate pronunciation, regional suitability or educational quality.

Before a production update, integrate from the current remote main without overwriting concurrent work, verify the current tldraw licence, run `npm run check`, review representative desktop and mobile lesson flows for each locale and confirm English and Spanish remain functional. Verify the resulting deployment URL, expected audio and hosting headers. Document pending native, educator and family review honestly.
