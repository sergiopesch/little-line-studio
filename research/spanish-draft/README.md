# Spanish lesson draft — not for publication or narration

`lessons.es-419.json` is the initial machine translation draft for all 30 lessons and their 730 stages. It is not approved for use with children and must not be used to generate audio. The runtime does not import it. Separate [source-linked editorial files](../spanish-reviewed/) have since been compared with the English lessons and compiled into the lazily loaded local Spanish catalogue; the language picker remains disabled pending final language, voice and experience review. The original [Cat](../spanish-pilot/cat.es-419.json) and [Sun](../spanish-pilot/sun.es-419.json) pilots remain historical inputs.

The initial non-Cat text was translated locally, without sending lesson content to an external service, using the Apache-2.0 Helsinki-NLP OPUS English–Spanish model in the `michaelfeil/ct2fast-opus-mt-en-es` CTranslate2 conversion. It is machine output, not Venezuelan language review. The lesson titles, several examples, and recurring subject terms have received targeted corrections; the remaining text still contains awkward phrasing and may reverse or distort an instruction. For example, the first pass rendered the apple's dip as a sauce or bath, an elephant's trunk as a tree trunk, and an ice-cream scoop as a news scoop. Avoid equating the limited automated vocabulary audit with verification of meaning.

Each entry stores a SHA-256 fingerprint of the current English text, so `tests/spanish-lessons.test.js` flags source changes and missing fields. It also checks a small list of identified incorrect terms and obvious English words. It cannot establish factual fidelity, optionality in prose, child-friendly tone, or correct spatial directions; a bilingual reviewer must inspect every text field against its source and reconcile source changes before recording or publication. The Spanish voice and recording script must use only reviewed, approved text. A cost estimate derived from this draft is approximate and is not permission to generate audio.
