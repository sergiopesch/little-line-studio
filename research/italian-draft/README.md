# Italian machine first pass — not for release

`lessons.it-IT.json` contains a local, unreviewed machine first pass of the 29 non-Cat lessons, generated from the complete English catalogue with the Apache-2.0 `manancode/opus-mt-en-it-ctranslate2-android` conversion of `Helsinki-NLP/opus-mt-en-it`, revision `50d67d1ceac4d3a35746c053a546f07f6eff9976`. The document records the hashes of the model and tokenizer files. The translation was performed locally; no lesson text was sent to a translation service. The first pass contains omissions, wrong meanings and awkward language. In an initial test, “whisker” became “clown”; other sampled output omitted instructions and mistranslated drawing terms. Do not use these texts with children or generate speech from them.

The untouched raw machine file is retained for provenance. Separately authored records under `research/italian-reviewed/<level>/` override it for the offline inventory, but do not enable the language. These records represent assistant review of source wording and stage/stroke geometry, not review by a native speaker, educator, child, or family. The preserved Cat pilot is in `research/italian-pilot/` and is assistant-reviewed with independent human review pending.

Run `node scripts/validate-italian-catalogue.mjs` for the current exact counts and integrity checks. Run `node scripts/validate-italian-catalogue.mjs --require-assistant-review` to assert that every lesson has an assistant-reviewed record. The test suite also verifies that the command fails when an unreviewed record is substituted. Neither command approves release or checks semantic meaning. The source hash covers the entire lesson object and geometry, and all stages, phases, required text and IDs must match. Visual/playback review and independent human review remain separate gates.

Reproducing the local machine pass requires separate `ctranslate2` and `sentencepiece` packages and the pinned model. `node scripts/italian-source.mjs` exports source text; `scripts/draft-italian-local.py` accepts an explicit source, model directory and new output path. It does not contact any provider, refuses to overwrite its output, and records model hashes. Model weights and temporary translation environment are not part of the repository.
