# Spanish from Spain: preparation handoff

This is an **offline draft**, not a releasable locale. It was prepared against standalone repository commit `cceb5d65213b1682e74fd439847f6679b4e071fb`. It has 30 complete lesson records, 730 stages and 1,460 instruction/hint texts, 207 UI strings, dynamic labels and a Cat pilot. The language is not registered or selectable, and there are no Spain audio files or availability entries.

## Offline editorial and geometry pass

The Spain wording starts from `src/spanish-lessons.es-419.json`, itself an assistant-reviewed draft awaiting independent native review. This pass compared all 30 English lesson records and all 730 stages with their Spain drafts, including titles, written instructions, spoken passages, Help hints, distinct adult notes, simplification and transfer text. It checked the 207 static UI strings against their English keys and audited the source's dynamic and accessibility paths. The wording now uses, for example, *ceras*, *seta*, *cuenco*, *plátano*, *melocotón*, *hierba* and *virutas de colores*, with Spain plural address where the adult and child are addressed together. It corrects errors introduced by earlier mechanical substitutions, including *se podéis*, masculine plátano agreement, crayon agreement, inconsistent plural forms and the mushroom safety note. This is an assistant editorial pass, not an independent native-speaker, child, family or educator review.

For the visual cross-check, we inspected source-derived static line contact sheets for all 30 lessons and each of their 500 draw stages, with the current stroke highlighted against earlier strokes. The other 230 stages (30 observe, 170 colour, 30 explore) were checked against the English text and authored stage identity, not against rendered colour animation. These diagrams are an approximation of the source coordinates, not a browser recording: they do not establish pen-lift rendering, colour appearance, timing or perceptual alignment. In particular, real tldraw animation and full browser playback still require review. The fruit-bowl upper banana edge is a continuous source stroke even though the English narration says to lift; this draft describes the continuous demonstration and offers a gap as the child's choice. The robot's antenna tip lies about one source coordinate from the line, so the draft says *near* rather than requiring contact. These are locale wording decisions only; English and geometry are untouched.

The UI audit covered the source paths for home, language picker and availability, catalogue and preview, adult gate and sound options, settings and privacy, lesson controls and Help, pause/resume and finish dialogs, status and playback errors, timeline/progress labels, demonstration labels, and application and board error boundaries. The draft includes static copy, proposed `Castellano · España` metadata and dynamic helpers for stage/board labels and estimates. Tests check all source literals used directly in `t(...)` and all 730 dynamic stage/board results. Conditional keys, native screen-reader announcements and responsive layout still require end-to-end review during future integration; this locale remains unregistered, so no es-ES UI or accessibility browser run has been claimed.

A Spain Spanish speaker should review every lesson, UI and audio text for idiom, pronunciation and age-appropriate tone, with special attention to the wording/geometry decisions above and all safety guidance. Educator and family review remain desirable. AI checks and source diagrams cannot establish native quality, teaching effectiveness or accessibility.

Each lesson record binds the entire current English lesson, including geometry and timing, and the inherited Spanish source text using SHA-256 over JavaScript `JSON.stringify`. UI source dictionaries are bound separately. Run `node scripts/validate-spanish-spain-draft.mjs` after changes: it rejects stale source, missing or reordered lessons, stages or phases, missing text, changes to allowed fields, mismatched UI keys and pilot text drift. The check does not assess translation quality. The branch contains drafts rather than a generator that can overwrite reviewed content; update hashes only after actually re-reviewing changed source.

`cat-pilot.es-ES.json` is a **text-only selection**: 12 Cat instruction/hint clips spanning observation, drawing, colour and exploration, plus a greeting. The complete Cat lesson text, including all 42 instruction/hint keys, is in the catalogue. The preview selected by the user is Carolina — Warm & Expressive (`BkOojM1ZhtSAHgsAkMx2`); that selection is not approval of generated speech, a production run, a provider permission route or spending. The selected greeting and excerpts are proposals for a first audition, not a request to call a provider. The 13 proposed texts total 1,841 Unicode code points at initial preparation; count exact approved request text again before any spending decision. This count is not a price, a credit guarantee, or permission to generate.

`node scripts/plan-spanish-spain-offline.mjs` produces a deterministic character inventory for the current full draft; pass `--full` to inspect every text and key. It counts Unicode code points and reports repeated text separately. The digest identifies this text inventory only: it does not bind model, settings, provider requests or approved costs. Draft edits change the digest and counts, and provider billing and deduplication must be verified separately. The command makes no network requests and cannot generate audio.

## Audio and interaction acceptance, once pilot audio exists

Use the existing speech recipe (`loudnorm=I=-20:TP=-2:LRA=7`, mono 44.1 kHz MP3) as the initial matching target, not a guarantee of equal perceived loudness. Decode every pilot file, record duration and measured integrated loudness/true peak, check clipping and unexpected silence, and compare representative Spain clips with existing lessons. Review short clips carefully: loudness measurements on short speech can be unstable. Audition voice and music together on desktop and mobile at comfortable volumes and document actual results rather than inferring quality from targets.

Exercise a full Cat lesson in the app with an adult: the demonstration is watched while drawing stays on paper; instructions finish before quiet practice and the next step; More time holds; Replay and Help interrupt correctly; Pause immediately silences both streams and does not advance; resume requires the adult gate and does not catch up; voice starts while the existing music continues and ducks smoothly, then music recovers; mute, voice-off, audio failure and background/foreground behavior work; listen across the music loop boundary. Measure event timing and music playback continuity around voice onset and transitions, and listen for clicks, jumps, awkward gaps and abrupt level changes. Do not change shared mixing behavior in this locale task. A test fixture is not a substitute for real audio, human listening or a child/family acceptance test.
