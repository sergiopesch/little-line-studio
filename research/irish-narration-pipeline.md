Its hash binds the source text, locale, voice, model, request fields, endpoint, encoding and generator contract. Re-run it after source changes and discard stale plans from dispatch. ## Offline staging and verification

After all planned cache entries are received, `python3 scripts/irish-narration.py bundle` uses existing complete receipts or normalises already-received raw responses locally, and creates a staged bundle. Missing or unknown receipts fail closed, without generation or retry. It reuses the existing generator's bundle layout. Run `python3 scripts/irish-narration.py validate --bundle media/elevenlabs/bundles/<plan-hash>` to compare that bundle with the exact current plan and authored texts. The inherited checks verify complete key coverage, canonical identities, voice and settings, receipts, asset hashes, file encoding and measured durations. The adapter additionally checks the approved voice and guarded dialogue fields, prohibits new music, fully decodes the audio and requires all 30 lessons.

Validated output is written only to the new ignored `media/elevenlabs/irish-validated/<plan-hash>/` directory as `narration-index.en-IE.json`, `narration-durations.en-IE.json`, `narration-manifest.en-IE.json` and `narration-availability.en-IE.json`. The index and duration map cover sample, instructions and hints. The manifest explicitly records native-speaker and full human listening review as pending. Assets remain in the verified bundle; validation does not activate the locale, change runtime/UI files, or deploy. The coordinator owns integration, copying content-addressed assets, release and browser checks. Do not treat metadata presence or automatic checks as human review. If validation fails, keep evidence and reconcile the cause before any paid retry.

Run `python3 tests/irish-narration-test.py` for focused offline checks. The Node test suite invokes the same checks via `tests/irish-narration.test.js`. Full bundle validation is necessarily pending until all paid responses and receipts exist.
