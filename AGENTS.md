# Little Line Studio

This is the standalone public Vercel repository. Preserve the parent-supervised, paper-first drawing experience and existing product direction.

- Use the real read-only tldraw teaching board. Never bypass its licence enforcement. No-key production builds must retain the clearly labelled licence-review page and exclude lesson/SDK JavaScript.
- Keep microphone, camera, uploads, runtime cloud AI, accounts, tracking and stored child profiles absent. The supervision acknowledgement is a local declaration, not verified parental consent or identity.
- The authored controller owns progression. Narration has no settings or progression authority. Preserve generous quiet practice, unlimited Pause, More time and Replay, optional manual controls, open-ended exploration and no catch-up after interruptions.
- Preserve adult-gated audio, default-on music with opt-out/mute, immediate interruption silence, reduced motion, accessible targets and focus states.
- Never generate paid media without explicit authorization and a bounded budget. Builds and tests must remain offline with respect to generation services.
- Change only files needed for the task. Keep credentials, media caches, provider receipts, output and local deployment configuration out of Git.
- Run `npm run check` after implementation changes. For deployment changes, verify the live headers, missing/private paths, audio range playback and English/Spanish browser flows. Update relevant documentation.
- Vercel publishes only `dist/client`, with headers from `vercel.json` checked against `config/security.js`. Do not reintroduce legacy Sites identifiers or packaging into this repository.
